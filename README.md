## 🚀 功能特性

- 🌸 **二次元视觉**：粉紫渐变、动态打字标题与角色展示墙。
- ✨ **轻量动效**：动态徽章、访问计数与贡献蛇形动画。
- 🤝 **双人共享**：为协作、分享和温暖的小互动而设计。
- 🧩 **易于定制**：换掉用户名、角色图或配色，就能变成自己的风格。

## 🛠️ 快速开始

```bash
# 把 WeiErLiTeo 换成你的 GitHub 用户名
 git clone https://github.com/WeiErLiTeo/DuoShare.git
 cd DuoShare
 npm install
 npm start
```

> `npm start` 需要仓库内的 `package.json` 已定义 `start` 脚本；如果项目使用 Vite 等工具，请按项目实际脚本改成 `npm run dev` 等命令。

## 🔮 看板娘与互动效果

GitHub README 不会执行普通网页中的 `<script>`，所以 Live2D 不可能只靠在这里粘贴脚本就固定显示在 GitHub 页面右下角。要让看板娘真正动起来，请将组件放到实际部署的网站 HTML 中；下面是 Live2D Widget 项目的使用文档：

- [Live2D Widget 使用说明](https://github.com/stevenjoezhang/live2d-widget)
- [Live2D Widget 网页接入示例](https://github.com/stevenjoezhang/live2d-widget/blob/master/README.en.md)

如果 DuoShare 本身有网站页面，把脚本加到网站模板里，而不是 `README.md`。模型角色需要另行选择并确认授权，不能默认脚本会自动提供薇尔莉特、芙莉莲、蕾姆、拉姆或波奇酱的 Live2D 模型。
