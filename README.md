## 🎀 项目简介

<p align="center">
  <strong>DuoShare</strong> 是一个用于双人共享与协作的小天地。<br />
  把有趣的想法、温柔的设计和一点点魔法，认真地写进每一次提交里。<br />
  <sub>此处的 GIF 会持续循环播放；没有网页脚本、没有 Live2D 挂件，只有 README 自己就能展示的动态素材！</sub>
</p>

<p align="center">
  <img src="https://capsule-render.vercel.app/api?type=rect&color=0:FF77B7,25:C084FC,55:7C9DFF,80:73E2E8,100:FFB86C&height=5&section=footer" width="100%" alt="Rainbow anime divider" />
</p>

## 🚀 功能特性

- 🌸 **二次元浓度超标**：芙莉莲、薇尔莉特、蕾姆／拉姆、波奇酱、菲伦、初音未来等动态 GIF 轮番登场。
- ✨ **动效叠满**：渐变波浪横幅、无限打字动画、动态徽章、萌系访问计数与贡献蛇蛇。
- 🤝 **双人共享**：为协作、分享和温暖的小互动而设计。
- 🧩 **可以继续扩建**：GIF 素材有来源链接；也附有可选工作流，能将动图保存到自己的仓库，之后由本地路径显示。

## 🛠️ 快速开始

```bash
git clone https://github.com/WeiErLiTeo/DuoShare.git
cd DuoShare
npm install
npm start
```

> `npm start` 需要项目的 `package.json` 已配置 `start` 脚本；若实际项目使用 Vite、Flutter 或其他技术栈，请把启动命令换成仓库里的真实命令。
